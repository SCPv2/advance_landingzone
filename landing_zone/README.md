# Landing Zone 구성

## Cloud Control 생성
- 기본 조직 단위: `Security`
- 추가 조직 단위: `Sandbox`
- 공유 Account 구성
  - Log Account
    - Log Account 명: `Log Archive`
    - 이메일: ID+1@Domain
  - Audit Account
    - Audit Account 명: `Audit`
    - 이메일: ID+2@Domain
- Account 액세스 구성: `ID Center를 통한 Account 액세스`
- 탐지 가드레일: 탐지 가드레일 활성 체크
